# Implementation Plan: Drivers Tab

**Input**: Feature specification from `/specs/001-drivers-tab/spec.md`

---

## Summary

Document and enhance the existing drivers ag-grid. The grid already displays the current season's drivers via TanStack Query. The enhancement adds a `YearSelector` dropdown (2023/2024/2025) in the top-right of the page. Selecting a year fetches that season's driver roster from OpenF1 via a two-step dependent query (sessions → drivers) and refreshes the grid. The selected year is persisted in the URL as a `?year=` search param.

## Implementation Detail

### 1. `useDriversByYear(year)` — new hook in `useOpenF1.js`

```js
export function useDriversByYear(year) {
  const { data: sessions = [] } = useSessions({ year, session_type: "Race" });
  const lastSessionKey = sessions.at(-1)?.session_key;
  return useDrivers(
    { session_key: lastSessionKey },
    { enabled: Boolean(lastSessionKey) }
  );
}
```

**Key concept — dependent queries**: The `useDrivers` call does not fire until `lastSessionKey` is truthy. `enabled: false` tells TanStack Query to hold the query in a pending state. Once `useSessions` resolves and `lastSessionKey` has a value, `enabled` becomes `true` and the drivers fetch fires automatically. No `useEffect`, no manual state coordination.

**Why `sessions.at(-1)`**: The `/sessions` API returns sessions in chronological order. The final Race session is the last round of the season (Abu Dhabi / Las Vegas / etc.) and has the complete, stable end-of-season driver lineup. Confirmed via live API: 2023 final session_key=9197 returns all 20 drivers correctly.

### 2. `YearSelector.jsx` — new component

- Salt DS `Dropdown` with three string items: `"2023"`, `"2024"`, `"2025"`
- Controlled: receives `value` (number) and `onChange(year: number)` as props
- Converts string selection to number before calling `onChange`

### 3. `DriversGrid.jsx` — accept `year` prop

```js
// Before
const { data: drivers = [], isLoading } = useDrivers({ session_key: "latest" });

// After
const { data: drivers = [], isLoading } = useDriversByYear(year);
```

The component prop signature changes from `{ onDriverOpen }` to `{ year, onDriverOpen }`.

### 4. `HomePage.jsx` — read/write year from URL

```js
const [searchParams, setSearchParams] = useSearchParams();
const year = Number(searchParams.get("year") ?? "2025");
const handleYearChange = (newYear) => setSearchParams({ year: String(newYear) });
```

Layout: `FlexLayout justify="space-between"` header row (page title left, `YearSelector` right) above the grid.
